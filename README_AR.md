# جنب بيتك

تطبيق دليل محلي عربي (نسخة تجريبية أولية) يعمل داخل WebView على أندرويد.

## البناء
يفتح GitHub Actions ملف `.github/workflows/build-apk.yml` ويبني نسخة Debug APK عند كل push إلى الفرع الافتراضي.

## ملاحظات مهمة
- البيانات في هذه النسخة محفوظة محليًا داخل المتصفح فقط.
- لا توجد قاعدة بيانات مشتركة أو تسجيل دخول أو لوحة إدارة فعلية.
- لا يوجد ربط فعلي بفيسبوك أو واتساب.
- ملف APK الناتج للتجربة وليس إصدارًا موقعًا للنشر العام.

## البناء محليًا
```bash
gradle assembleDebug
```

ملف الناتج: `app/build/outputs/apk/debug/app-debug.apk`.
